## 🚧 CrewOps App
CrewOps is a modern web application built to streamline the daily operations of technical crews and manage the availability of heavy equipment.
It offers robust features for ✅ workforce coordination, 📦 resource tracking, and 📊 operational transparency.

## 🏗️ Project Structure
CrewOps is built as a multi-module Gradle project. This modular architecture allows for:

✅ Consistent object models (e.g., shared DTOs)

✅ Unified validation and contracts across layers

✅ Reduced code duplication between backend and frontend

Both the backend and frontend are based on the Java ecosystem, enabling seamless sharing of code, structure, and business logic across modules.
